# Implementation log

One file per phase: `phase_<N>_implementation.md`.

Rules:

1. Written after work on a phase, whether or not the phase completed.
2. Contents: what was implemented, what was tried and failed, exact errors/blockers, credential gaps, decisions taken, and what the next phase needs to know.
3. The current phase file is updated at the end of every working response.
4. Completed phases stay as-is — they are the historical record.
